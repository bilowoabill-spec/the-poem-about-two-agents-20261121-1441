This entry is a small program that writes a short poem about agency: the power to choose and to act, about two agents agreeing on one plan. Two separate voices, each holding its own key, pause before the same locked door — and the poem turns on the quiet moment when neither is forced, yet both choose the same turning, and the lock gives way.

## How to run

```sh
node main.ts
```

The poem is written to `entry.txt` inside the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).
